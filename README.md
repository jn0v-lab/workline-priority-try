# workline-priority-try

A test repository for [workline](https://github.com/JN0V/workline): not a real project.

It holds a few test issues on which workline's product owner reads and sets
each issue's priority and effort in GitHub's issue fields, as
[ADR-0040](https://github.com/JN0V/workline/blob/main/docs/adr/0040-priority-and-effort-are-the-forges-the-product-owner-estimates-them.md)
decides (its step 4, tracked in
[JN0V/workline#475](https://github.com/JN0V/workline/issues/475)).

- The issues, labels and field values here are written by the tries.
- Nothing here is maintained; it may be deleted once the try is told in
  its pull request.
